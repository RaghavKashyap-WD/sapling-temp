# Sapling — Temporary Landing Page

A deliberately lightweight one-week marketing/coming-soon page built with React + Vite.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Notes

- No backend.
- The waitlist form currently shows a browser alert only.
- Replace the temporary form with a real service if you want to collect emails.
- Main page lives in `src/main.jsx`.
- Styling lives in `src/styles.css`.
